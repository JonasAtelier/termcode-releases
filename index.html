termcode apt repository

termcode is a VS Code-style code editor and Git panel that runs inside your terminal. This is its apt repository, for Debian and Ubuntu on amd64 and arm64.

Install

sudo curl -fsSLo /usr/share/keyrings/termcode.gpg https://jonasatelier.github.io/termcode-releases/termcode.gpg
echo "deb [signed-by=/usr/share/keyrings/termcode.gpg] https://jonasatelier.github.io/termcode-releases stable main" \
  | sudo tee /etc/apt/sources.list.d/termcode.list
sudo apt update && sudo apt install termcode

New versions then come with sudo apt upgrade.

Signing key

The repository is signed with termcode releases, fingerprint
8DF2288B3BD908A32CD57371E81C850CE8AD044F

Check it with gpg --show-keys /usr/share/keyrings/termcode.gpg.
